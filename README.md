# AWS EC2アーカイブシステム構築

## 概要
AWS（Amazon EC2）環境におけるアーカイブシステム基盤構築プロジェクト。
コンプライアンス強化・監査対応に向けた社内データ（メール・ファイル等）の
一元管理と長期保管環境を構築しました。

## システム構成
| サーバー | 台数 |
|---|---|
| チャットアーカイブサーバー | 2台 |
| メールアーカイブサーバー | 4台 |
| アーカイブ検索サーバー | 2台 |
| DBサーバー | 2台 |
| **合計** | **10台** |

## 使用技術
- **OS**：Windows Server 2019 / 2022
- **環境**：AWS EC2 / Hyper-V / Microsoft Entra ID
- **ツール**：PowerShell / JP1 / IIS / Apache
- **DB**：SSMS（SQL Server Management Studio）
- **連携**：Microsoft 365

## 担当業務
- AWS EC2上でのWindows Server仮想サーバー（Hyper-V）構築
- ZLUAパッケージインストール・パッチ適用・各種設定
- IIS設定・SSL証明書作成・設定
- SaaSアプリとの連携設定
- 動作確認書作成・動作テスト・本番リリース
- 運用マニュアル・作業手順書・パラメータシート作成
- 顧客主導の運用への引継ぎ支援

## 成果
- 開発環境でのサーバー構築から単体テスト・結合テスト、
  本番導入まで一連の工程を担当
- 構築手順書・運用手順書を整備し顧客側での運用開始を円滑に支援
- Windows Serverの構築からパッケージ導入まで一貫して対応

## 期間
2025年10月 〜 2026年3月
